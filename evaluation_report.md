# Evaluation Report

In this project, the FLAN-T5 model was tested on instructions from the Dolly-15k dataset.

Two prompting approaches were used:

1. Zero-shot prompting
2. Few-shot prompting

## Results

The results show that the model is able to generate responses for most instructions.

However, the answers are not always correct when compared with the true responses in the dataset.

In some cases, the few-shot prompting approach improved the model's response.

## Observations

- The model understands the instruction format.
- Some answers are partially correct.
- Few-shot prompting can help the model perform better in some cases.

## Conclusion

Instruction prompting plays an important role in how well a model follows instructions.

While the model performs reasonably well, it still makes mistakes, showing that prompting strategy and model limitations affect performance.
