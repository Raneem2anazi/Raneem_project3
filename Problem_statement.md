# Problem Statement

Large Language Models (LLMs) are able to generate responses based on instructions. However, their performance depends on how the instructions are provided.

The goal of this project is to evaluate how well a language model can follow instructions.

In this project, we use the Dolly-15k dataset, which contains human-written instruction and response pairs.

We test a language model using two prompting strategies:

1. Zero-shot prompting
2. Few-shot prompting

The model responses are then compared with the true answers from the dataset.

This helps us understand how prompting techniques affect the model's ability to follow instructions.
